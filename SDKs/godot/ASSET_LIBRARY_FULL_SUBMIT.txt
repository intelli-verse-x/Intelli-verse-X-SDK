--- DESCRIPTION (plain text — paste exactly; Asset Library uses plain text) ---
IntelliVerseX SDK provides a complete game backend for Godot 4.2 and newer. It adds authentication (device, email, Google, Apple, custom), session restore, profile management, wallet and economy, leaderboards, cloud storage, RPC calls, and real-time socket support using the Nakama server.

Requirements: Godot 4.2 or newer (tested up to 4.6). You must install the official Nakama Godot addon for backend features. Get it from https://github.com/heroiclabs/nakama-godot and copy the addons/com.heroiclabs.nakama folder into your project addons folder.

The download is a Godot project ZIP. It contains addons/intelliversex (this SDK) and an example scene. To use in your own project: copy the addons/intelliversex folder from the downloaded project into your project addons folder. To run the example: open the downloaded project in Godot and press F5.

Enable the IntelliVerseX plugin in Project, Project Settings, Plugins. Then create an IVXConfig with your Nakama host, port, and server key and call IntelliVerseX.initialize(config). See the included example script for the full flow.

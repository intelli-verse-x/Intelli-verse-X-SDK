# IntelliVerseX Godot SDK — Changelog

## [5.2.0] — Godot 4.2+

- Initial Godot 4 addon release.
- Auth (device, email, Google, Apple, custom), session restore.
- Profile, wallet (RPC), leaderboards, cloud storage, RPC, real-time socket.
- Requires [Nakama Godot addon](https://github.com/heroiclabs/nakama-godot) for backend.
- Graceful error when server unreachable; clear message and tip in example.

# Cursor skills (optional)

This folder is **tracked in git** (see [`.gitignore`](../../.gitignore)) so teams can share Cursor skill trees.

- **Primary publishable skills:** [`skills/`](../../skills/README.md) (e.g. [`skills/intelliversex-game-sdk/SKILL.md`](../../skills/intelliversex-game-sdk/SKILL.md)).
- **Platform SDK pointers:** [`skills/platforms/`](../../skills/platforms/README.md).
- **Narrative guides:** [`docs/guides/skills/`](../../docs/guides/skills/index.md).

Add per-topic `SKILL.md` files here only when you want them in-repo for Cursor auto-discovery; keep content aligned with `docs/guides/skills/` to avoid drift.

**Also see:** [`.agents/skills/`](../../.agents/skills/README.md) for the same packs under the generic `~/.agents/skills/` / `<project>/.agents/skills/` layout used by other agent clients.

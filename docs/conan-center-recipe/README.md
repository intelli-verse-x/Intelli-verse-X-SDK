# Conan Center recipe (copy into your fork)

These files are ready to copy into [conan-center-index](https://github.com/conan-io/conan-center-index) when submitting **intelliversex-cpp**.

**Copy:**

- `all/conanfile.py` → `recipes/intelliversex-cpp/all/conanfile.py`
- `all/conandata.yml` → `recipes/intelliversex-cpp/all/conandata.yml`

Then replace `REPLACE_WITH_SHA256` in `conandata.yml` with the SHA256 of the v1.5.0 source tarball (see `docs/conan-center-submission.md`).

Full steps: **docs/conan-center-submission.md**

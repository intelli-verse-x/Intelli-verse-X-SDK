Frequently Asked Questions

What does $1.99 per game include?
Full SDK access for one game title — identity, backend (175+ RPCs), monetization, social, competition, retention, and push notifications. No monthly fees, no revenue share, no hidden costs.
Are the 31 AI Agent Skills really free?
Yes. Agent Skills run locally in your IDE via Cursor. They help you generate GDDs, characters, audio, environments, store assets, and more — completely free, forever.
Which game engines are supported?
Unity, Unreal Engine 5, Godot 4, Roblox, Defold, Cocos2d-x, JavaScript/TypeScript, C++, Java/Android, Flutter, and Web3. All engines share the same backend and feature set.
Do I need to self-host the backend?
No. We host the full Nakama cluster for you. For Starter tier, it's shared infrastructure. Pro and above get dedicated resources. You can also self-host — the backend is almost open-source.
What's the difference between Content Factory and Agent Skills?
Agent Skills are free IDE-based tools for design-time content generation. Content Factory (Pro+) is an agentic cloud pipeline — it generates store assets, trailers, marketing kits, and landing pages at scale with AI quality review.
Can I upgrade or downgrade anytime?
Yes. Start at $1.99 (one-time per game) and upgrade when you need AI, Content Factory, or self-hosting. Pro ($29/mo) and Studio ($499/mo) are month-to-month — no annual lock-in, cancel anytime, and your existing game keeps working on the last active tier.
What does Content Factory generate from my GDD?
Content Factory takes your Game Design Document (stored as S3 JSON metadata) and produces ready-to-use 2D characters with sprite sheets, 3D models with rigging, sound effects and BGM, parallax environments, marketing visuals, store screenshots, trailers, and landing pages. Every asset passes a multi-model AI Council review for quality. Available on Pro (2D assets) and Studio+ (full 2D + 3D + audio + video).
How do AI Companions work in my game?
AI Companions are conversational NPCs powered by our Intelligence LLM Layer. They support multiple personas (Fortune Teller, Coach, Storyteller, etc.), real-time voice via OpenAI Realtime or Kokoro TTS, and GAGAvatar-driven 3D faces. The backend intelligently routes between self-hosted vLLM (zero cost) and cloud providers with automatic fallback. Pro includes 50K tokens/mo; Studio offers unlimited tokens.
What can I do with Quests Economy?
Quests lets you create engagement campaigns — daily goals, streaks, challenge quests, lotteries, and gift card rewards. Run campaigns like "Top 3 players get $50 gift cards" or "Complete 7-day streak for bonus XUT." It supports 22 quest action types, 6 quest buckets, and cash-out via gift cards, PayPal, crypto, and Robux. Publishers earn 20–40% revenue share. Available on Pro (daily goals, streaks) and Studio+ (gift cards, cashback, lotteries).
What does the Self-Host Stack include?
Studio ($499/mo) includes the full self-hostable stack: customized Nakama 3.x (175+ RPCs, dual wallets, 21 Hiro live-ops modules), vLLM for zero per-token LLM inference (Qwen 32B default), ComfyUI for image generation, and Docker Compose for quick setup. Enterprise adds KEDA auto-scaling and private cloud deployment. You get full data sovereignty and eliminate API costs that typically run $2,000+/mo at scale.
How does IntelliVerseX compare to Firebase + PlayFab + ad SDKs?
IntelliVerseX replaces your entire backend stack in one integration: Firebase (auth, storage, analytics), PlayFab (live-ops, economy, matchmaking), GameAnalytics, Unity Ads, ironSource, LootLocker, and Photon Voice. Instead of managing 5-8 SDKs with separate dashboards and billing, you get one SDK, one backend, one bill. Developers typically save 2-3 months of integration time and $500-2,000/mo in combined SaaS costs.

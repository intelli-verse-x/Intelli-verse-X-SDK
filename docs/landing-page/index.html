Frequently Asked Questions
What does $1.99 per game include?
Full SDK access for one game title — identity, backend (175+ RPCs), monetization, social, competition, retention, and push notifications. No monthly fees, no revenue share, no hidden costs.
Are the 31 AI Agent Skills really free?
Yes. Agent Skills run locally in your IDE via Cursor. They help you generate GDDs, characters, audio, environments, store assets, and more — completely free, forever.
Which game engines are supported?
Unity, Unreal Engine 5, Godot 4, Roblox, Defold, Cocos2d-x, JavaScript/TypeScript, C++, Java/Android, Flutter, and Web3. All engines share the same backend and feature set.
Do I need to self-host the backend?
No. We host the full Nakama cluster for you. For Starter tier, it's shared infrastructure. Pro and above get dedicated resources. You can also self-host — the backend is almost open-source.
What's the difference between Content Factory and Agent Skills?
Agent Skills are free IDE-based tools for design-time content generation. Content Factory (Pro+) is an agentic cloud pipeline — it generates store assets, trailers, marketing kits, and landing pages at scale with AI quality review.
Can I upgrade or downgrade anytime?
Absolutely. Start at $1.99 (one-time per game) and upgrade to a monthly plan when you need more power. Pro and Studio are month-to-month — no annual lock-in, cancel anytime, and your existing features keep working.

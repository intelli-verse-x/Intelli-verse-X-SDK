# IntelliVerseX SDK — Photon (optional)

```json
"com.intelliversex.sdk.photon": "https://github.com/Intelli-verse-X/Intelli-verse-X-SDK.git?path=Packages/com.intelliversex.sdk.photon"
```

1. Install **Photon PUN2** from the Unity Asset Store into your project (sandbox already has it under `SDKs/unity/editor/Assets/Photon`).
2. Add this package.
3. Set your Photon App ID via consumer config — the core package no longer ships a shared App ID.

Core multiplayer path remains **Nakama / MultiplayerKernel**. Photon is never required for Control Center → Play.

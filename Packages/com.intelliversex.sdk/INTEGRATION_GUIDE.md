# Integration guide (canonical)

> Legacy dual-init docs were removed in 5.9.x cleanup.

## First run

1. **IntelliVerseX → Control Center**
2. Paste **Game ID** / Nakama host into `IVXBootstrapConfig`
3. **Add bootstrap** to the scene
4. Press **Play**

## Advanced / optional

**IntelliVerseX → Advanced Setup** — dependencies, project checks, demo scenes.

## Do not use

- `IntelliVerseXManager` / `IntelliVerseXConfig` (retired)
- Old “SDK Setup Wizard” (replaced by Advanced Setup)

See `README.md` and `INSTALLATION.md`.

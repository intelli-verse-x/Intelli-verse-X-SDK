# IntelliVerseX SDK — Discord (optional)

```json
"com.intelliversex.sdk.discord": "https://github.com/Intelli-verse-X/Intelli-verse-X-SDK.git?path=Packages/com.intelliversex.sdk.discord"
```

Requires core `com.intelliversex.sdk`. Enable Discord on `IVXBootstrapConfig` after install. Discord Social SDK (`com.discord.social-sdk`) is detected via asmdef `versionDefines` (`INTELLIVERSEX_HAS_DISCORD`).
